# Changelog

## 1.0.1 — 2026-11-01

- Keep the standard MIT license text alone in `LICENSE` so GitHub can recognize it.
- Preserve all icon notices separately and inside the distributed CSS.
- Check the project license against GitHub's canonical MIT template during CI.
- No visual or behavioral CSS changes.

## 1.0.0 — 2026-11-01

- First standalone theme release, developed from Office Mock Clean 0.4.0.
- Native application styling, complete light/dark document surfaces and colored application ribbons.
- Documents, emails, meetings and native editable Markdown tables in reading view and Live Preview.
- User-configured text/interface/monospace fonts and text size.
- Document layout by default; `office-plain` opts out without inspecting Properties markup.
- Offline geometry-only SVG assets, no runtime plugin or JavaScript, no `!important` or `:has()`.
- Official Obsidian Stylelint rules, Chromium 114 compatibility checks, native integration QA and reproducible release packaging.
