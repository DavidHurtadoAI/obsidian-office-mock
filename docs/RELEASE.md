Office Mock 1.0.1 fixes automatic project-license detection.

- `LICENSE` contains the standard MIT text, without additional notes that interfere with GitHub's license recognition.
- Lucide/Feather notices remain in `THIRD_PARTY_NOTICES.md` and embedded in `theme.css`.
- CI checks the project license against GitHub's canonical MIT template.
- Theme CSS rules, appearance and native editing behavior are unchanged. This release updates licensing comments and metadata only.

For manual installation, download the ZIP and copy its `Office Mock` folder into `.obsidian/themes/`, then select Office Mock in Appearance settings. Disable the former `office-clean` snippet if installed. Optional examples and templates are included in the ZIP and repository.

After updating, rerun the Community directory's review to refresh license detection. This release does not claim acceptance into the directory. See the README and docs/VALIDATION.md for validation scope.
