First standalone release of Office Mock, an office-inspired theme with native light/dark application styling and four Markdown document views.

- Blue documents and email, purple meetings and green spreadsheets.
- Reading view and native Live Preview editing, including editable Markdown table cells.
- Your configured fonts and text size, offline SVG geometry and clean Markdown notes.
- No plugin, runtime JavaScript or remote assets. The ribbons and formula bar are decorative; the editor and tables are native Obsidian features.
- Official Obsidian Stylelint rules and Chromium 114 compatibility checks pass without disabled rules. Native integration QA covers 100 reading/editing checks in the canonical development vault.

For manual installation, download the ZIP and copy its `Office Mock` folder into `.obsidian/themes/`, then select Office Mock in Appearance settings. Disable the former `office-clean` snippet if installed. Optional examples and templates are included in the ZIP and repository.

This GitHub release is prepared for Community Themes submission; it is not yet listed or accepted in the community directory. See the README and docs/VALIDATION.md for compatibility and validation scope.
