# Community Themes preparation

Status: prepared for submission; not submitted or accepted into the community directory.

The repository includes `theme.css`, `manifest.json`, a project LICENSE, third-party notices, README, examples and `images/screenshot.png` (512 × 288). The release tag matches the manifest version and has `theme.css` and `manifest.json` as downloadable assets.

Validation uses the official `stylelint-config-obsidianmd` without disabling rules and an additional Chromium 114 compatibility target. There are no remote resources, runtime scripts, telemetry, `!important` declarations or `:has()` selectors. User fonts and native keyboard editing remain available.

To submit after publication, sign in to https://community.obsidian.md with the maintainer's Obsidian account, connect the GitHub account, add the repository `DavidHurtadoAI/obsidian-office-mock`, select Light and Dark modes and the screenshot path `images/screenshot.png`, then complete the directory's review. Resolve any remote scanner feedback before describing it as available in Community Themes.
